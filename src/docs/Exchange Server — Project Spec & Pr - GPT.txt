Architecture Decisions Made

The following decisions have already been finalized and should NOT be revisited unless a compelling reason emerges.

Matching is event-driven.
Trade price equals resting price.
FIFO within a price level.
match() executes exactly one trade.
process() owns the matching loop.
PriceLevel owns queue invariants.
OrderBook owns book structure.
OrderRequest is the public request model.
Order is an internal domain object.
Unit tests should verify behavior and invariants rather than implementation details.
Working Style Notes
Guided/Socratic discussion before implementation.
Understand why before writing code.
Small concrete examples before abstraction.
Code reviews should focus on architecture, invariants, and responsibility boundaries—not just correctness.
New architectural decisions should be captured as ADRs (Architecture Decision Records) so the reasoning behind design choices is preserved alongside the evolving codebase.
